## Лабораторна робота №1
**UML Modeling – Платформа бронювання готелів (Варіант 21)**

---

### Завдання
Лабораторне завдання складається з чотирьох частин, кожна з яких реалізовується як окрема UML-діаграма.

### Загальні рекомендації
1. Для першого завдання на діаграмі використання (**Use Case Diagram**) необхідно:
   - визначити та представити основних акторів системи;
   - показати їх взаємодію з системою (API інтеграція).
2. При створенні діаграми класів (**Class Diagram**) слід використовувати можливості об'єктно-орієнтованого програмування:
   - класи;
   - успадкування;
   - поліморфізм;
   - інкапсуляцію.
3. Використання таймерів на діаграмі активності (**Activity Diagram**) слід здійснювати лише за необхідності.

---

### Предметна область
Додавання нової мережі готелів до платформи та процес резервування номерів.

---

### Частина 1 — Use Case Diagram
Описати варіанти використання для додавання нової мережі готелів до платформи на рівні інтеграції API між платформою та мережею готелів.

### Частина 2 — Class Diagram
Представити множину об'єктів, необхідних для:
- зберігання інформації про готелі, відгуки, оцінки, локації;
- інформації про вільні номери;
- ієрархії користувачів та типів кімнат.

### Частина 3 — Activity Diagram
Описати процес резервування номеру в готелі. Показати ситуацію, при якій бажаний номер стає недоступним в процесі резервування (Critical Point).

### Частина 4 — Sequence Diagram
Продемонструвати послідовність дій:
- резервування номеру;
- блокування коштів на рахунку;
- надсилання підтвердження реєстрації електронним листом.

---

### Результат виконання
Робота містить чотири окремі UML-діаграми:
- Use Case Diagram
- Class Diagram
- Activity Diagram
- Sequence Diagram
