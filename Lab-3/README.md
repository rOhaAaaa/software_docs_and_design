# Лабораторна робота №3: Патерн MVC (Booking.com)

Цей проєкт є веб-додатком для управління системою бронювання готелів (Booking.com), побудованим на основі архітектурного шаблону **MVC (Model-View-Controller)**.

## 🚀 Функціонал (CRUD)
- **Read:** Перегляд списку всіх готелів з їх рейтингом та локацією.
- **Create:** Додавання нового готелю через веб-формат (автоматично створюється нова локація).
- **Update:** Редагування існуючих даних готелю (назва, рейтинг, країна, місто).
- **Delete:** Видалення готелю з бази даних.

## 🏗 Архітектура проекту
- **Model (Модель):** Класи ORM (`models.py`), що описують сутності предметної області (`Hotel`, `Location`, `HotelChain`) та взаємодіють з базою даних SQLite.
- **View (Представлення):** HTML-шаблони в папці `templates/` (`index.html`, `add_hotel.html`, `edit_hotel.html`). Використано Bootstrap 5 та FontAwesome для сучасного UI.
- **Controller (Контролер):** Файл `app.py`, що обробляє HTTP-запити (GET, POST), керує маршрутизацією та делегує обробку даних.
- **BLL (Бізнес-логіка):** Клас `HotelService` (`src/bll/hotel_service.py`), який інкапсулює логіку вичитки та збереження даних, роблячи Контролер "тонким".

## 🛠 Технології
- **Backend:** Python, Flask, SQLAlchemy
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, Bootstrap 5

## 📥 Як запустити
1. Активуйте віртуальне середовище: `venv\Scripts\activate`
2. Встановіть залежності: `pip install -r requirements.txt` та `pip install Flask`
3. Запустіть сервер: `python app.py`
4. Відкрийте в браузері: `http://127.0.0.1:5000`
